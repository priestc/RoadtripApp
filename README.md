# RoadtripApp

Navigation built for long road trips — see [DESIGN.md](./DESIGN.md) for the full product design.

This is the web app MVP: Google sign-in plus a driving-preferences onboarding flow. Built with [Next.js](https://nextjs.org) (App Router, TypeScript, Tailwind CSS) and [Firebase](https://firebase.google.com) (Auth + Firestore).

## Getting started

See [SETUP.md](./SETUP.md) for one-time Firebase project setup.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
